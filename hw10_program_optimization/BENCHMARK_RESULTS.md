# Результаты оптимизации

## Описание изменений

Оптимизирована функция `GetDomainStat` для повышения производительности при обработке больших JSON файлов.

### Основные изменения

1. **Использование `jsoniter.Get()` вместо полного unmarshaling**
   - Вместо парсинга всей JSON структуры в `User`, извлекается только поле `Email`
   - Это снижает количество аллокаций и ускоряет обработку

2. **Использование стандартных функций Go**
   - `strings.HasSuffix()` для проверки суффикса домена
   - `strings.ToLower()` для нормализации регистра
   - Код стал более читаемым и поддерживаемым
